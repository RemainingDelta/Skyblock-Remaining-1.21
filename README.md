# Skyblock-Remaining-1.21

A client-side Fabric mod for Minecraft 1.21.10 providing quality-of-life HUD overlays for Hypixel Skyblock.

## Features
- Coordinate HUD with toggleable visibility and draggable positioning
- In-game config screen via `/sbr` or Mod Menu

## Requirements
- Minecraft 1.21.10
- Fabric Loader
- Fabric API
